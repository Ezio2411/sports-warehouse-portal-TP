# Sports Warehouse Portal

A starter website managed using Git and GitHub for ICTPRG530.

## Pages

- `index.html` — company introduction and product information.
- `login.html` — login form prototype.
- `blank.html` — starter page for future content.

Each page includes navigation links to all three pages.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the other pages.

An internet connection is needed to load the external background image.

## Manual testing

- Open each page and check that its content displays.
- From each page, test all three navigation links.
- Check that the login form requires a username and password.

The login form is a visual prototype. It does not authenticate users,
save credentials or provide working password recovery.

## Development workflow

Work is tracked through GitHub Issues and a Project board.

Changes are made on task branches, tested, committed and pushed.
A pull request links the changes to their issue and records the review
before merging into main.
